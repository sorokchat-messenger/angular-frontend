# Project Policy - Sorokchat Messenger

**Тип за ISO 15289:2019:** Policy

**Версія:** 1.0

**Дата:** 2026-09-19

## 1.Мета та цінності проєкту
Sorokchat Messenger - безпечний веб-месенджер для усіх, хто цінує конфіденційність. Головна цінність - **приватність користувача понад усе**

## 2. Принцип роботи із вимогами
1. Кожна вимога має бути оформлена за критеріями якості ISO/IEC/IEEE 29148:2018 (необхідна, однозначна, повна, сингулярна, здійснена, перевірювана, коректна, відповідна, доречна).
2. Кожна вимога має бути **трасованою** до бізнес-потреби та тесту.
3. Зміна вимоги оформлюється через Change Request (див. `request/`).
4. Усі вимоги до безпеки проходять обов'язковий review з боку security-експерта.

## 3. Принципи роботи із архітектурою
1. Архітектурний опис ведеться за ISO/IEC/IEEE 42010:2022.
2. Frontend реалізується за методологією **Feature-Sliced Design (FSD)**.
3. Стек: Angular (TypeScript).
4. Архітектурні рішення фіксуються у вигляді ADR (Architecture Decision Records)
   в `description/architecture/`.

## 4. Принципи безпеки

1. **Zero-trust** - жоден компонент не довіряє іншому за замовчуванням.
2. **End-to-end шифрування** повідомлень.
3. **MAC (Message Authentication Code)** для перевірки цілісності.
4. **Контрольована зміна ключів** - з журналюванням і підтвердженням.
5. Паролі - взагалі не зберігаються на клієнтській частині.
6. Сесії - короткоживучі токени + refresh.

## 5. Правила комітів та документації

1. Усі коміти документації починаються з префіксу `docs:`.
2. Документи в `docs/` підтримуються в актуальному стані.
3. Мова документації: українська (з англійськими технічними термінами).

## 6. Обмеження проєкту

- Поточна платформа: **Web only**.
- Майбутнє розширення: мобільні (iOS/Android) та десктопні клієнти.
- Очікувана кількість користувачів у чаті: **до 1000**.
