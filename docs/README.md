# Документація проєкту Sorokchat Messenger

> Цей документ описує цільовий стан системи (target design), а не поточний стан реалізації в коді. Поточна реалізація в src може відрізнятися від описаного стану до досягнення MVP.

Структура документації відповідає стандарту **ISO/IEC/IEEE 15289:2019** (7 типів інформаційних елементів життєвого циклу).

| Папка | Тип ISO 15289 | Зміст |
|-------|---------------|-------|
| `description/` | Description | Операційна концепція, архітектурний опис |
| `plan/` | Plan | Плани управління вимогами та верифікації |
| `policy/` | Policy | Політика проєкту |
| `procedure/` | Procedure | Процедури життєвого циклу вимог |
| `report/` | Report | Звіти про трасування та верифікацію |
| `request/` | Request | Шаблони запитів на зміну |

Зміст специфікацій відповідає **ISO/IEC/IEEE 29148:2018**,
зміст архітектурного опису — **ISO/IEC/IEEE 42010:2022**.
