# Опис проєкту

**Версія**: **1.0.0**

**Автор**: **Сороковський Андрій**

Проєкт Sorokchat Messenger призначений для забезпечення безпечного обміну повідомленнями між користувачами. Основні сценарії використання: реєстрація, авторизація, створення та керування чатами, обмін текстовими повідомленнями, доступ до історії переписки, а також налаштування профілю та параметрів користувача.

Архітектура проєкту побудована на розділенні функцій за доменами, що забезпечує читабельність, масштабованість і простоту супроводу. Взаємодія між клієнтом і сервером реалізована через API та WebSocket-подключення, а локальні дані зберігаються у безпечному середовищі з частковим шифруванням.
