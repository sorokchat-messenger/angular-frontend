# Sorokchat Messenger — опис проєкту

**Версія**: **1.0.0**

**Автор**: **Сороковський Андрій**

Sorokchat Messenger — це веб-месенджер для обміну повідомленнями, управління чатами та взаємодії користувачів у реальному часі. Проєкт реалізовано як клієнтський застосунок на Angular з модульною архітектурою Feature-Sliced Design. Основний функціонал включає авторизацію, реєстрацію, перегляд історії повідомлень, роботу з чатами та налаштування користувача.

Проєкт орієнтований на безпечну роботу з даними, зберігання локальних станів у IndexedDB, обробку сесій через сервер і підтримку сучасних веб-стандартів. Метою є створення стабільного, масштабованого та безпечного сервісу для комунікації.
