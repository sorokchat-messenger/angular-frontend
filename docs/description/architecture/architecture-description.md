# Architecture Description - SorokChat Messenger

**Тип за ISO 15289:2019:** Description

**Стандарт:** ISO/IEC/IEEE 42010:2022

**Версія:** 1.0

## 1. Ідентифікація системи

- **Назва:** SorokChat Messenger (frontend)
- **Призначення:** веб-клієнт для безпечної комунікації
- **Стек:** Angular, TypeScript, Feature-Sliced Design, WebCrypto API

## 2. Зацікавлені сторони та їхні проблеми

| Стейкхолдер | Проблема (Concern) |
|-------------|--------------------|
| Користувач | Конфіденційність, простота UI |
| Адміністратор чату | Управління ключами, контроль доступу |
| Security-експерт | Аудит, криптостійкість, цілісність |
| Frontend-розробник | Модульність, тестованість, FSD |
| Власник продукту | Метрики успіху, еволюція до mobile/desktop |

## 3. Аспекти (Aspects)

- **Безпека** - наскрізний аспект для всіх подань.
- **Офлайн-режим** - перетинає шари `features` та `entities`.
- **Локалізація** - стосується усіх UI-компонентів.

## 4. Точки зору (Viewpoints)

| Точка зору | Проблеми | Моделі | Стейкхолдери |
|------------|----------|--------|--------------|
| Функціональна | Сценарії, фічі | Component Diagram, Use Case | Розробники, PM |

## 6. Ключові архітектурні рішення (ADR)

| ID | Рішення | Альтернативи | Обґрунтування |
|----|---------|--------------|---------------|
| ADR-01 | Angular + FSD | React + Redux, Vue | Типізація, модульність FSD, підтримка enterprise |
| ADR-02 | WebCrypto API | crypto-js | Нативна швидкість, без залежностей |
| ADR-03 | AES-256-CBC | ChaCha20 | AES-256-GCM, GCM дає MAC «з коробки» |
| ADR-04 | IndexedDB для офлайну | localStorage | Обсяг, асинхронність |
| ADR-05 | WebSocket | Long-polling | Real-time, низька затримка |

## 7. Відповідності (Correspondences)

- Кожна функціональна вимога SyRS ↔ слайс FSD у SRS.
- Кожна безпекова вимога ↔ ADR-03 + WebCrypto.
- Кожен стейкхолдер ↔ хоча б одна точка зору.
