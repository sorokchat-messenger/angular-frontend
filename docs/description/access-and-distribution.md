# Розповсюдження, доступ та контроль прав

**Версія**: **1.0.0**

**Автор**: **Сороковський Андрій**

Для проєкту обрана модель SaaS з підпискою та можливим Freemium-етапом. Базовий доступ надається безкоштовно, але з обмеженим набором функцій. Повний функціонал доступний за платною підпискою, яка діє на визначений період і автоматично продовжується, якщо користувач не відмовився від неї.

Ролі та права користувача перевіряються на сервері. Клієнт не визначає дозволи самостійно; він лише відображає доступний інтерфейс залежно від результатів серверної перевірки. Такий підхід дозволяє гарантувати безпечний доступ до платних функцій і запобігти обходу обмежень через локальні маніпуляції.
