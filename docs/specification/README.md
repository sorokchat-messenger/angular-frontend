# Sorokchat Messenger — технічна специфікація

**Версія**: **1.0.0**

**Автор**: **Сороковський Андрій**

Цей документ описує технічні вимоги та основні складові проєкту Sorokchat Messenger. Проєкт призначений для забезпечення безпечного обміну повідомленнями, роботи з чатами, авторизації користувачів та управління правами доступу.

## 1. Ціль системи
Створити веб-месенджер, який підтримує реальний час, безпечне зберігання даних, контроль доступу до функцій і просту масштабованість.

## 2. Основні функціональні вимоги
- реєстрація користувача;
- авторизація та вихід з облікового запису;
- створення та керування чатами;
- надсилання та отримання повідомлень;
- збереження історії переписки;
- контроль ролей і доступу до функцій.

## 3. Нефункціональні вимоги
- безпечне зберігання чутливих даних;
- підтримка HTTPS та захищених WebSocket-з’єднань;
- локальне шифрування чутливих даних;
- серверна перевірка ролей і підписки.
