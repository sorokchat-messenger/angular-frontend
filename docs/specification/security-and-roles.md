# Специфікація безпеки та ролей

**Версія**: **1.0.0**

**Автор**: **Сороковський Андрій**

## 1. Ролі користувачів
У проєкті передбачено використання ролей для керування доступом. Основні ролі визначаються на сервері та використовуються для обмеження доступу до певних функцій і операцій.

## 2. Контроль доступу
Контроль доступу реалізовано на сервері. Клієнт не має самостійно визначати пріоритети доступу, а лише отримує результат перевірки від сервера. Це дозволяє уникнути обходу обмежень і забезпечує безпечну модель SaaS-подходу.

## 3. Захист даних
- шифрування повідомлень і чутливих даних — AES-CBC;
- перевірка цілісності — HMAC;
- відкритий ключ використовується для перевірки підпису, закритий — лише на сервері.
