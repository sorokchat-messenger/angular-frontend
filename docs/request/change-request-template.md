### 1. Опис зміни

### 3. Пов'язані вимоги

| UI/UX | Новий екран «Налаштування 2FA» |
| Безпека | Посилення автентифікації |
| Тести | +3 E2E-тести |

### 5. Альтернативи

1. SMS-коди - менш безпечно, залежить від оператора.
